快速开始

本地需 Python 3.11 + pandas/numpy；数据库用抓取脚本生成（见 README）

# 1. 安装依赖
pip install pandas numpy requests beautifulsoup4

# 2. 抓取全A股日线数据，生成 a_share_daily.db
python3 fetch_all.py
python3 add_adjusted_prices.py   # 后复权
python3 add_benchmarks.py         # 基准指数

# 3. 运行回测：低价20股，月度调仓
python3 run_backtest.py --strategy strategies.low_price:LowPriceStrategy \
    --start 2010-01-01 --end 2024-12-31 --freq monthly --n 20 \
    --save-equity equity.csv

# 4. 换一个策略，只需改 --strategy
python3 run_backtest.py --strategy strategies.low_pb:LowPbStrategy --freq monthly

数据与局限

  • 复权价格：收益一律用后复权价计算，分红送转已还原，避免除权日假暴跌。
  • 幸存者偏差：已扫描补齐 379 只退市股历史数据，大幅降低偏差。
  • 历史估值：PE/PB/PS/市值覆盖 2018 年至今（东财数据），更早区间无估值。
  • 交易设定：T 日选股、T+1 开盘成交，含佣金/印花税/滑点与一字板过滤，无未来函数。
  • 注意事项：回测绝对收益请审慎看待，建议重点用于策略间相对比较；本页不构成投资建议。
